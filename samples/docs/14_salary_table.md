# 연봉 테이블

기밀 문서다. 인사팀 중 기밀 열람 권한이 있는 사람과 임원만 열람한다.

## 직급별 연봉 범위 (2026년)

| 직급 | 연봉 범위 |
|---|---|
| 사원 | 3,800만 원 ~ 4,600만 원 |
| 선임 | 4,600만 원 ~ 5,800만 원 |
| 책임 | 5,800만 원 ~ 7,500만 원 |
| 수석 | 7,500만 원 ~ 9,500만 원 |

개발 직군에는 위 범위에 더해 기본 연봉의 10%를 직무 수당으로 지급한다.

## 신입 초봉

- 일반 직군: 4,000만 원
- 개발 직군: 4,400만 원 (직무 수당 포함)

## 2026년 연봉 인상 재원

- 인상 재원은 총 인건비의 5%로 한다.
- 개인별 인상률은 인사평가 등급에 따른다.
- 연봉 범위의 상한을 넘는 인상분은 일시금으로 지급한다.

## 경력직 채용

경력직의 연봉은 직전 연봉의 최대 15% 인상 범위 안에서 정하며, 해당 직급 범위의 상한을 넘을 수 없다. 상한을 넘겨야 하면 대표의 승인을 받는다.
