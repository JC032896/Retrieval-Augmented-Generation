# IT 보안 정책 부속서

IT 보안 정책 본문에 없는 세부 조항을 정한다. 조항 코드는 본문과 같은 체계를 따른다.

## 계정

### SEC-PW-03 계정 공유 금지

개인 계정은 다른 사람과 함께 쓸 수 없다. 팀 공용 작업이 필요하면 공용 계정을 따로 신청한다.

### SEC-PW-04 서비스 계정 비밀번호

서버와 배치 작업에 쓰는 서비스 계정의 비밀번호는 20자 이상이어야 하며, 180일마다 변경한다. 서비스 계정 비밀번호는 비밀 관리 시스템에만 보관한다.

### SEC-MFA-02 인증 기기 교체

인증 앱을 설치한 휴대폰을 바꾸거나 잃어버리면 헬프데스크에서 본인 확인을 거쳐 인증 기기를 다시 등록한다. 등록 전까지는 임시 인증 코드를 하루에 한 번 발급받을 수 있다.

## 데이터

### SEC-DATA-01 문서 보안 등급 표시

대외비 이상 문서는 첫 쪽 머리말에 보안 등급을 표시한다.

### SEC-DATA-04 클라우드 저장소

업무 파일은 회사가 승인한 클라우드 저장소에만 저장한다. 개인 계정의 클라우드 저장소(개인 드라이브 등)에는 업무 파일을 저장할 수 없다.

## 기기

### SEC-DEV-02 외부 저장 매체 등록

업무에 쓰는 외부 저장 매체는 보안 담당자에게 등록한 뒤에만 쓸 수 있다. 등록하지 않은 매체는 사내 PC에서 읽기 전용으로 동작한다.
