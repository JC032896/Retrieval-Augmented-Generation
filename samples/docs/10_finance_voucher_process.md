# 전표 처리 절차

## 월 마감 일정

- 전월 전표의 마감은 매월 5영업일이다.
- 마감 이후에 들어온 전표는 다음 달 회계에 반영한다.

## 법인카드

- 법인카드를 쓰면 3일 이내에 HB-Expense에 증빙(영수증)을 올린다.
- 증빙이 2주 넘게 올라오지 않으면 재무팀이 해당 카드의 사용을 정지한다.
- 1회 100만 원 이상 지출은 사전에 품의(지출 결의)를 받아야 한다.

## 주요 계정과목 코드

| 코드 | 계정과목 | 예시 |
|---|---|---|
| 811 | 복리후생비 | 회식비, 경조금, 건강검진 |
| 812 | 여비교통비 | 출장비, 택시비 |
| 813 | 접대비 | 고객 식사, 선물 |
| 830 | 소모품비 | 사무용품 |
| 831 | 지급수수료 | 외부 용역, 클라우드 사용료 |

## 접대비 처리

- 접대비 전표에는 접대 상대방의 회사명과 인원을 반드시 적는다.
- 1인당 10만 원을 넘는 접대비는 팀장의 사후 확인을 받는다.

## 세금계산서

- 공급자에게서 받은 세금계산서는 발행일이 속한 달의 다음 달 10일까지 재무팀에 전달한다.
