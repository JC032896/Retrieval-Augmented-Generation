# 출장비 규정

## 사전 승인

- 국내 출장: 소속 팀장의 승인을 받는다.
- 해외 출장: 임원의 승인을 받는다. 출발 2주 전까지 신청해야 한다.

## 국내 출장

| 항목 | 기준 |
|---|---|
| 일비 | 1일 2만 5천 원 |
| 숙박비 (서울, 광역시) | 1박 12만 원 한도 |
| 숙박비 (그 외 지역) | 1박 9만 원 한도 |
| 교통 | KTX 일반실 또는 고속버스. 자가용은 km당 250원 |

당일 출장에는 숙박비를 지급하지 않고, 일비의 절반을 지급한다.

## 해외 출장

| 항목 | 직원 | 임원 |
|---|---|---|
| 일비 | 1일 60달러 | 1일 80달러 |
| 숙박비 (A 지역: 미국, 유럽, 일본) | 1박 200달러 한도 | 1박 250달러 한도 |
| 숙박비 (B 지역: 그 외) | 1박 150달러 한도 | 1박 200달러 한도 |
| 항공 | 이코노미석 | 비행 6시간 이상이면 비즈니스석 |

## 정산

출장에서 돌아온 날로부터 7일 이내에 경비 시스템 HB-Expense에 영수증을 올리고 정산을 신청한다. 기한을 넘기면 팀장의 사유서가 필요하다. 해외 출장비는 출장 마지막 날의 서울외국환중개 매매기준율로 원화 환산한다.
