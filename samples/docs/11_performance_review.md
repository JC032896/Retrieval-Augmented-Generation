# 인사평가 기준

취업규칙 제30조에 따른 인사평가의 세부 기준이다. 대외비 문서이므로 인사팀 중 대외비 열람 권한이 있는 사람과 임원만 열람한다.

## 평가 구성

- 성과 평가 70%: 연초에 합의한 목표의 달성도
- 역량 평가 30%: 협업, 문제 해결, 전문성의 3개 항목

## 평가 등급과 배분 비율

| 등급 | 배분 비율 | 의미 |
|---|---|---|
| S | 10% | 기대를 크게 뛰어넘음 |
| A | 25% | 기대를 뛰어넘음 |
| B | 50% | 기대 수준 |
| C | 10% | 기대에 못 미침 |
| D | 5% | 기대에 크게 못 미침 |

팀원이 10명 미만인 팀은 배분 비율을 본부 단위로 합산해서 맞춘다.

## 보상 반영

| 등급 | 연봉 인상률 | 성과급 (기본 연봉 대비) |
|---|---|---|
| S | 8% | 20% |
| A | 6% | 12% |
| B | 4% | 6% |
| C | 1% | 0% |
| D | 0% | 0% |

연간 등급은 6월 평가와 12월 평가의 평균으로 정한다.

## 승진 요건

- 사원에서 선임: 사원으로 3년 이상 근무하고, 직전 2회 평가가 모두 B 이상
- 선임에서 책임: 선임으로 4년 이상 근무하고, 직전 2회 평가 중 1회 이상 A 이상

## 성과 개선 프로그램

D 등급을 2회 연속 받은 직원은 3개월 동안 성과 개선 프로그램(PIP)에 참여한다. 프로그램을 마친 뒤에도 개선되지 않으면 직무 전환을 검토한다.
